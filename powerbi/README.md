# Power BI Reports

This folder contains the Power BI reporting artifacts for the E-commerce Order & Customer Analytics project.

## Report Pages

### Sales Overview
- Total sales
- Total orders
- Average order value
- Daily sales trends
- Revenue by product

### Customer Insights
- Total customers
- Orders by customer
- Customer distribution by country
- Customer sign-ups over time
- Country and signup-date slicers

## Planned Artifacts

- Dashboard screenshots
- Power BI report file (`.pbix`), if suitable for sharing

## Notes

The report was created in Power BI Desktop using analytics-ready Gold tables from Azure Databricks. The current report is an initial portfolio version.

Check report contents and data sensitivity before sharing. Do not include credentials or private customer information.
