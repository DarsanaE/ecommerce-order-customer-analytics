# Azure Data Factory

This folder contains documentation and exported configuration for the Azure Data Factory orchestration layer.

## Responsibilities

- Connect Azure Data Factory to Azure Data Lake Storage Gen2 and Azure Databricks.
- Orchestrate Bronze-to-Silver and Silver-to-Gold processing.
- Manage pipeline execution and monitor activity failures.
- Support troubleshooting and pipeline reruns.

## Planned Artifacts

- Pipeline JSON exports
- Pipeline activity configuration
- Linked service and dataset configuration templates, where appropriate

## Security

Before committing exported configurations, remove credentials, access tokens, connection secrets, and sensitive environment-specific information. Never commit live secrets or private customer data.
